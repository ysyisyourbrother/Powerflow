# （一）节点数据

节点表每行对应一个电网拓扑节点。节点有功、无功采用“节点净注入”口径，正值表示节点向电网注入功率，负值表示节点从电网吸收功率；最终功率方向与符号约定以赛事方发布的数据字典为准。

| 列 | 含义 | 数据示例 | 物理信息/用途说明 |
| --- | --- | --- | --- |
| 节点 ID | 节点编号 | 1、2、3… | 节点唯一标识，用于潮流计算、拓扑建模、邻接关系和 GNN 图结构中定位节点，通常对应 bus_id。 |
| 节点类型 | 节点电气类型 | Vθ、PV、PQ | 用于区分节点在潮流计算中的电气类型，常见类型包括平衡节点 Vθ、发电机节点 PV 和负荷节点 PQ。不同类型节点的已知量与待求量不同。 |
| 发电（MW） | 节点发电有功功率 | 21.4 | 节点所接发电机向系统注入的有功功率，单位为 MW。功率方向及正负号以赛事方发布的数据字典为准。 |
| 发电（MVar） | 节点发电无功功率 | 12 | 节点所接发电机向系统注入的无功功率，单位为 MVar，对电压支撑和无功平衡具有重要影响。功率方向及正负号以赛事方发布的数据字典为准。 |
| 负荷（MW） | 节点有功负荷 | 21.4 | 节点负荷吸收的有功功率，单位为 MW，是节点有功功率平衡的重要组成部分。功率方向及正负号以赛事方发布的数据字典为准。 |
| 负荷（MVar） | 节点无功负荷 | 12 | 节点负荷吸收的无功功率，单位为 MVar，影响节点电压水平和系统无功分布。功率方向及正负号以赛事方发布的数据字典为准。 |
| 无功补偿（MVar） | 已投入无功补偿容量 | -127.6 | 表示节点已投入运行的电容器、电抗器、SVG、SVC 等无功补偿设备容量或等效无功注入。正值表示容性补偿，负值表示感性补偿；最终以赛事方发布的数据字典为准。 |
| 电压等级（kV） | 节点所属电压等级 | 500 | 例如 500 kV、220 kV、110 kV 等，用于区分主网层级，也可用于误差归一化、节点分类和图特征构造。 |
| 电源标幺值（P.U.） | 节点电压标幺值 | 1.034 | 节点电压标幺值，单位为 P.U.。与电压幅值对应，通常满足“电压幅值＝标幺电压×基准电压”。 |
| 电压幅值（kV） | 节点实际电压幅值 | 505 | 节点电压实际幅值，单位为 kV。与标幺电压对应，通常满足“电压幅值＝标幺电压×基准电压”。 |
| 电压相角（°） | 节点电压相角 | 10.3166 | 节点电压相量的相角，单位为度。节点间相角差是决定有功潮流分布的重要变量。 |

# （二）电网拓扑及支路数据

边表采用稀疏邻接表，即邻接矩阵的坐标表示形式。每行对应一条输电线路或变压器支路，首端 ID 与末端 ID 共同确定支路连接的两个拓扑节点。

| 列名 | 字段含义 | 数据示例 | 物理信息说明 | 备注 |
| --- | --- | --- | --- | --- |
| 首端 ID | 支路首端节点编号 | 101 | 表示支路起始侧节点编号，通常对应节点表中的 node_id 或母线编号。 | 需与节点表中的节点编号保持一致。 |
| 末端 ID | 支路末端节点编号 | 205 | 表示支路终止侧节点编号，通常对应节点表中的 node_id 或母线编号。 | 需与节点表中的节点编号保持一致。 |
| 支路类型 | 支路设备类型 | L / T | 表示支路设备类型，包括线路、变压器或其他等值支路。 | L 表示线路，T 表示变压器。 |
| 并联标志 | 并列运行支路标识 | 1 | 首末端 ID 相同的多条支路为并列运行支路，该标识可识别多回并列运行支路中的第 N 条支路。 | 示例 xx 甲线/xx 乙线并列运行，首端末端节点 ID 相同，标识：1/2 分别标识 xx 甲线或 xx 乙线。   注：不同并联标志区分不同支路，但并联标志 1、2 与线路名称中的 xx 甲线、xx 乙线或 xxI 线，xxII线无绑定关系。 |
| 电阻 R | 支路电阻 | 1/2 | 表示支路串联阻抗中的电阻分量，反映有功损耗特性。 | 赛事方应在数据字典中明确采用标幺值或有名值，并统一基准与单位。 |
| 电抗 X | 支路电抗 | 0.00231 | 表示支路串联阻抗中的电抗分量，反映无功压降和潮流分布特性。 | 线路和变压器通常均包含该参数；赛事方应统一参数基准与单位。 |
| 对地电纳 B/2 (b/2) | 支路对地电纳 | 0.0248 | 表示线路单侧充电电纳或等效并联电纳，主要影响支路无功注入。 | 线路通常有该值，变压器可能为空。 |
| 首端有功（MW） | 首端有功潮流 | 0.1352 | 表示从支路首端流入或流出的有功功率，单位 MW。 | 需明确正方向，一般按首端到末端为参考方向。 |
| 末端有功（MW） | 末端有功潮流 | 125.36 | 表示支路末端侧的有功功率，单位 MW。 | 与首端有功符号通常相反，二者差值反映损耗。 |
| 首端无功（MVar） | 首端无功潮流 | 1.45 | 表示支路首端侧的无功功率，单位 MVar。 | 受线路电抗、对地电纳、电压水平影响较大。 |
| 末端无功（MVar） | 末端无功潮流 | 36.82 | 表示支路末端侧的无功功率，单位 MVar。 | 与首端无功共同反映支路无功消耗或发出情况。 |
| 额定电流（A） | 支路额定电流 | 2000 | 表示支路允许长期运行的额定电流限值。 |  |
| 额定容量（MVA） | 变压器额定容量 | 2000 | 表示变压器的额定容量。 |  |
| 首端电压等级（kV） | 首端节点电压等级 | 525 | 表示支路首端所连接节点的电压等级，如 525 kV、230 kV 等。 | 线路和变压器均需提供；变压器两端电压等级通常不同。 |
| 末端电压等级（kV） | 末端节点电压等级 | 500 | 表示支路末端所连接节点的电压等级。 | 首末端电压等级不同时，通常表明该支路为变压器或等值变换支路。 |
