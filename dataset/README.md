# dataset/ —— 比赛数据集

存放比赛方提供的输入数据(算例、量测数据、场景文件等)。

建议:
- 原始数据保持只读,不要在本目录里直接改写
- 大文件(>10MB)建议用 `.gitignore` 排除,或改用 Git LFS,避免队友 clone 太慢
- 若数据有固定的目录约定,在这里写清楚,例如:

```
dataset/
├── raw/          # 比赛给的原始数据,不改动
├── processed/    # 预处理脚本产出的中间数据(可重新生成,通常不提交)
└── README.md     # 数据格式说明
```

现在目录是空的,等拿到比赛数据后填入。
