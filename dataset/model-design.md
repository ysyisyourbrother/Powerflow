# 神经网络模型设计：v1 复盘与 v2 方案

状态：v1 已实现并完成首轮训练；本版加入设计评审和 v2 方案，v2 尚未实现。  
上一册：[比赛对齐数据集教程](competition-dataset-guide.md)  
比赛字段表：[competition-dataset.md](competition-dataset.md)  
数据字段手册：[competition_v1 README](ieee39/processed/competition_v1/README.md)  
模型代码：[src/powerflow/model](../src/powerflow/model)  
训练入口：[src/examples/train_gnn.py](../src/examples/train_gnn.py)

> **第一版变比约定（修订版）**
>
> 比赛字段表没有单独给变压器变比。v1 的处理方式是：
>
> - 普通线路没有变比，等效变比就是 1，这是精确的；
> - 变压器支路**不把变比作为输入**，但训练标签仍然是用真实变比算出来的，
>   不是把数据重新按变比 1 生成；
> - v1 直接回归支路潮流，模型只能从标签中间接学习变压器变比的修正量；
> - `aux["tap"]`、`aux["tap_raw"]`、`aux["shift_deg"]` 不进入模型输入，
>   不进入损失，不用于初始化可学习变比；只用于物理复算、误差分析和自检；
> - 如果以后要用物理解析式复算支路潮流，不能再简单假设变压器变比等于 1。
>   实测表明，变比按 1 会让变压器支路的无功误差达到上百 MVar；
>   要么拿到真实变比，要么从训练标签中学习一个“等效变比”。
>
> 一句话：**“不输入变比”不等于“物理上假设变比等于 1”。**
> 前者是 v1 的做法，后者只适合普通线路，不适合变压器。

## 0. 先看结论

### 0.1 v1 能跑通，但还不能算“好基底”

v1 的工程链路是完整的：数据读取、归一化、图张量、训练、早停、测试评估、
checkpoint 都跑通了。电压幅值预测也已经很强，待预测节点的 MAE 约为
0.00088 p.u.。

但用它作为后续所有优化的基底，目前有五个问题，按优先级排列：

1. **没有基线，无法判断模型到底好不好。**
   补做的线性回归基线在相角差和支路有功上明显优于 v1。
   如果不先补基线，后面加层、加特征都可能是在错误方向上努力。

2. **损失函数和模型选择口径没有对齐官方指标。**
   v1 在标准化空间对六个输出等权做 Huber，这会让标准差小的无功通道
   获得更高的实际权重，有功和相角差反而被压住。结果就是：
   v1 的无功很好，但有功和相角差不如线性基线。

3. **输入特征太窄。**
   字段表明确给了节点类型、电压等级、首末端电压等级、并联标志，
   v1 全部没用。节点类型在 dropout 掩码下尤其重要，因为掩码模式
   已经不能完整反映节点的电气角色。

4. **支路五个量独立回归，没有物理一致性。**
   首端有功、末端有功、首端无功、末端无功是同一组电压和相角的
   解析结果。独立回归可能在数值上拟合得不错，但不满足节点功率平衡，
   也不满足支路两端功率关系。变压器变比缺失的误差也集中在这里。

5. **数据覆盖太窄。**
   当前数据只有一张拓扑，只扰动负荷，随机划分只是“同分布插值”。
   在这种数据上，模型很容易学到一个近似线性的映射，GNN 的图结构
   未必能体现出优势。

### 0.2 量化证据

用 v1 完全相同的训练/测试划分，做了一个简单的岭回归基线。
特征是掩码后的节点 P/Q/V、三个掩码，以及已知量的汇总统计。
测试集 199 条样本，结果如下：

| 输出 | 评估范围 | v1 GNN | 岭回归基线 | 谁更好 |
|---|---|---:|---:|---|
| Vm | 待预测节点 | 0.00088 p.u. | 0.00686 p.u. | GNN |
| 相角差 | 全部支路 | 0.0875 度 | 0.049 度 | 线性 |
| Pf | 全部支路 | 9.38 MW | 4.56 MW | 线性 |
| Pt | 全部支路 | 9.38 MW | 4.57 MW | 线性 |
| Qf | 全部支路 | 2.25 MVar | 4.82 MVar | GNN |
| Qt | 全部支路 | 2.49 MVar | 5.90 MVar | GNN |

这不是说 GNN 没用。它在电压和无功上明显更好，说明图结构和非线性
确实学到了东西。但**相角差和有功不如一个线性模型**，这是不能接受的。
一个合格的基底，至少应该在所有输出上不输给线性基线。

### 0.3 误差集中在变压器

按支路拆开看，v1 的误差高度集中在少数变压器支路。最典型的是
`branch 13`，它的真实变比是 1.07：

| 支路 | 类型 | 真实变比 | 相角差 MAE | Pf MAE | Qt MAE |
|---|---|---:|---:|---:|---:|
| branch 13 | 变压器 | 1.07 | 0.893 度 | 56.1 MW | 12.7 MVar |
| branch 19 | 变压器 | 1.07 | 0.14 度 | 6.8 MW | 5.8 MVar |
| 全部支路平均 | — | — | 0.0875 度 | 9.38 MW | 2.49 MVar |

branch 13 的相角差误差是全站平均的 10 倍。原因不是模型容量不够，
而是模型拿不到变比，只能从标签里间接猜。这个误差用“每支路偏置校准”
就能降 7% 到 8%，说明支路级的可学习修正是有价值的。

### 0.4 推荐路线

不要急着加层、加注意力、上图 Transformer。推荐顺序：

1. **先补基线**：均值、岭回归、牛顿法/状态估计、无图 MLP；
2. **先改评测**：把模型选择指标从“标准化 Huber”改成和官方指标一致的
   物理量指标；
3. **再改输入**：节点类型、电压等级、首末端电压等级、并联标志；
4. **再改输出**：节点功率平衡损失、支路一致性、可学习等效变比；
5. **最后改数据**：发电机出力、电压设定值、拓扑变化、更多电压等级。

## 1. 任务定义与评测口径

### 1.1 模型到底做什么

输入：

- 一张电网拓扑：节点、支路、R/X/B2、支路类型、节点类型、电压等级；
- 每个节点的部分量测：有功净注入 P、无功净注入 Q、电压幅值 V；
- 三个掩码，0 表示已知，1 表示待预测。

输出：

- 全部节点的电压幅值 Vm；
- 全部支路的相角差、首端有功、末端有功、首端无功、末端无功。

这是一个**带掩码的状态估计问题**，不是普通的多输出回归。

### 1.2 三种掩码对应三种数学问题

- `structural`：P 已知 38 个、Q 已知 29 个、V 已知 10 个，正好是标准
  潮流计算的输入。未知量和方程数相同，问题有唯一解。
- `dropout`：在 structural 基础上又藏掉一部分已知量。未知量多于方程，
  问题欠定，需要先验或正则化。
- `extra`：在 structural 基础上多揭示一部分未知量。方程多于未知量，
  问题过定，但数据自洽，可以用最小二乘。

这带来一个非常重要的结论：

> 如果比赛规则允许使用数值求解器，structural 掩码下直接用牛顿法就能
> 复现标签，误差只取决于收敛容差，基本是零。GNN 的价值主要在
> dropout、extra、跨拓扑泛化和推理速度，而不是在 structural 下和
> 牛顿法比精度。

必须先确认比赛规则：

- 是否允许使用牛顿法、状态估计、最小二乘等数值方法？
- 是否只允许一个前馈模型做端到端推理？
- 推理时间是否计入评分？
- 测试数据是否有量测噪声？

如果允许数值求解，那么“物理求解器”就是必须做的上限基线。
如果不允许，也仍然要把它作为误差分析工具，知道模型离物理真解有多远。

### 1.3 官方指标要先确认

当前文档只能给出内部代理指标。正式训练前必须确认：

- 官方指标是 MAE、RMSE、MAPE，还是按通道加权的综合分？
- Vm 和五个支路量是否等权？
- 已知节点的 Vm 是否计入总分？
- 支路是否按线路/变压器分组？
- 是否对高负荷、dropout 等难样本单独计分？

在官方指标确认之前，内部至少同时报告：

- 每个输出的物理单位 MAE 和 RMSE；
- 每个输出除以训练集标准差的归一化 MAE；
- 每个输出除以一个固定物理容差的归一化 MAE；
- 已知/未知 V、线路/变压器、三种掩码模式的拆分。

### 1.4 训练损失和模型选择指标要分开

训练损失负责提供梯度，模型选择指标负责挑 checkpoint。两者可以不同。

v1 用同一个标准化 Huber 做训练和早停，导致模型选择也被“无功优先”
的权重影响。v2 应该：

- 训练损失可以用 Huber，但权重按目标调整；
- 早停和选模用与官方指标一致的物理量综合分；
- 测试集只在最后报告一次，不能用来调参。

## 2. 字段边界：输入、标签、泄漏、不可用

先把四类东西分清楚。把它们都叫“泄漏”会掩盖真正的问题。

### 2.1 合法输入

| 字段 | 用途 | 说明 |
|---|---|---|
| 节点 P/Q/V 的已知位置 | 连续特征 | 未知位置是 0 占位，必须配合掩码 |
| 三个节点掩码 | 缺失模式 | 0 已知，1 待预测 |
| 节点类型 | 节点 one-hot | Vθ/PV/PQ，字段表明确提供，不是泄漏 |
| 节点电压等级 | 可选特征 | 当前全是 345 kV，真实数据会有多电压等级 |
| 支路首末端节点 | 图结构 | 0 基下标 |
| R、X、B/2 | 边特征 | 标幺值，B/2 就是 B/2，不再乘除 |
| 支路类型 | 边特征 | 线路/变压器；移相变压器按独立标志处理 |
| 首末端电压等级 | 边特征 | 变压器额定电压比，真实数据很重要 |
| 并联标志 | 可选边特征 | 同首末端的第几条并联支路 |

### 2.2 标签

| 字段 | 说明 |
|---|---|
| `targets.vm_pu` | 全部节点电压幅值 |
| `targets.dtheta_deg` | 首端相角减末端相角 |
| `targets.pf_mw`、`pt_mw` | 支路首末端有功 |
| `targets.qf_mvar`、`qt_mvar` | 支路首末端无功 |

这六个量是主监督目标。节点 P/Q 不是官方输出，不要当主标签。

### 2.3 解泄漏

这些量是潮流解的一部分，训练表里有，但推理时不能作为输入：

| 字段 | 为什么不能输入 |
|---|---|
| `aux_net_p_mw`、`aux_net_q_mvar` | 未知位置会直接给出答案 |
| `aux_va_deg` | 真实节点相角；当前协议不输出绝对相角，也不输入 |
| `target_*` | 就是标签本身 |
| `meta.loss_mw` | 网损是解出来的结果 |
| `meta.iterations`、`final_norm`、`initial_norm` | 求解过程信息，推理时不存在 |

`aux_va_deg` 可以在训练时作为**辅助损失**使用，但不能作为输入。
如果要用，必须做参考相角处理：只学相角差，或把所有相角减去同一个常数。
不能让模型依赖绝对相角。

### 2.4 未提供的拓扑参数

这些不是标签泄漏，而是比赛字段表没有提供，所以不能输入：

| 字段 | 说明 |
|---|---|
| `aux_tap`、`aux_tap_raw` | 变压器变比；字段表没有单列 |
| `aux_shift_deg` | 移相角；字段表没有单列 |
| `aux_rate_a_mva` | 额定容量；常规潮流不用 |
| `aux_status` | 投运状态；如果字段表提供，应按拓扑处理，而不是当连续特征 |

“不能输入”和“泄漏”是两件事。变比不是答案，它是被主办方拿掉的一个
拓扑参数。用 `aux_tap` 做输入，违反的是输入协议；用 `aux_net_p_mw`
做输入，才是直接偷看答案。

同理，不要用 `aux_tap` 去初始化一个“可学习变比”。那会让模型在训练时
依赖一个推理时拿不到的量。可学习变比只能从标签中自己学。

### 2.5 场景元数据和标识

| 字段 | 为什么不能进模型 |
|---|---|
| `meta.sigma` | 负荷缩放系数，生成信息，不是量测 |
| `meta.total_load_mw` | 总负荷；可能部分可算，但不是稳定可用的输入 |
| `meta.mask_mode` | 掩码模式；只能用于分层和误差分析 |
| `meta.sample_id`、`case_hash`、`topology_hash` | 样本标识，不是物理特征 |
| `node_ids`、`branch_ids` | 原始编号；直接做嵌入容易记住固定拓扑 |

注意：**“不要用原始编号做嵌入”不等于“不能有支路级校准参数”。**
在固定拓扑比赛里，给每条支路一个可学习的等效变比或偏置，是一个
物理校准参数，不是随便的 ID 嵌入。它的风险是换拓扑后不能直接迁移，
但在当前单拓扑数据上是合理的实验。

### 2.6 几个容易混淆的点

**节点类型不是泄漏。** 字段表明确给 Vθ/PV/PQ。v1 没用，是一个
可以补的输入，不是禁区。

**节点 P/Q 是净注入。** 有功等于发电减负荷；无功等于发电减负荷
再加无功补偿。不是节点负荷本身。

**B/2 是单侧充电电纳。** 不要再乘 2 或除 2。变压器 B/2 可能为 0，
靠支路类型区分，不要靠 B/2 是否为 0 判断类型。

**支路类型不要用互斥三分类。** 一台变压器可能同时有变比和移相角。
更稳的编码是三个独立二值标志：是否线路、是否变压器、是否有移相。
当前 case39 没有移相变压器，所以三分类暂时没问题，但真实数据会踩坑。

**已知 V 可以直接复制。** `mask_v == 0` 的节点，输入电压就是标签。
输出阶段直接写回，不浪费模型容量。但评估时要和未知节点分开报告。

## 3. 输入表示

### 3.1 v1 的输入

节点 `[N, 6]`：

| 通道 | 来源 | 处理 |
|---|---|---|
| P | `node_features[:, 0]` | 只用已知位置统计，未知置 0 |
| Q | `node_features[:, 1]` | 同上 |
| V | `node_features[:, 2]` | 同上 |
| mask_P | `node_masks[:, 0]` | 0/1 |
| mask_Q | `node_masks[:, 1]` | 0/1 |
| mask_V | `node_masks[:, 2]` | 0/1 |

支路 `[E, 6]`：

| 通道 | 来源 | 处理 |
|---|---|---|
| R | `branch_features[:, 0]` | 训练拓扑统计 |
| X | `branch_features[:, 1]` | 训练拓扑统计 |
| B/2 | `branch_features[:, 2]` | 训练拓扑统计 |
| type_line | `branch_type == 0` | 0/1 |
| type_trafo | `branch_type == 1` | 0/1 |
| type_phase | `branch_type == 2` | 0/1 |

这套输入干净、和当前数据完全对齐，但信息量偏少。

### 3.2 v2 建议的节点特征

| 特征 | 是否建议 | 理由 |
|---|---|---|
| P/Q/V 已知值 | 必须 | 主量测 |
| 三个掩码 | 必须 | 缺失模式 |
| 节点类型 one-hot | 建议 | 字段表提供；dropout 下仍能告诉模型节点角色 |
| 节点电压等级 | 建议 | 当前常数；真实数据多电压等级时必需 |
| 节点度数 | 可选 | 图结构统计，帮助模型区分枢纽节点 |
| 原始节点编号 | 不建议 | 容易记住固定拓扑 |

节点类型建议用 3 类 one-hot：PQ、PV、Vθ。如果数据里有孤立节点，
再加第 4 类。不要把它当成连续数值 0/1/2。

### 3.3 v2 建议的边特征

| 特征 | 是否建议 | 理由 |
|---|---|---|
| R/X/B2 | 必须 | 支路参数 |
| 是否线路/是否变压器/是否移相 | 建议 | 用独立二值标志，不用互斥三分类 |
| 首末端电压等级比 | 建议 | 变压器的额定电压比；用 `log(from_kv / to_kv)` |
| 并联标志 | 真实数据建议 | 同首末端的多条支路要靠它区分 |
| 原始支路编号 | 不建议 | 换拓扑失效 |

当前 case39 全是 345 kV，首末端电压等级比恒为 0（取对数后）。
这些通道现在是死通道，但加上不会有害，而且能让模型代码直接迁移到
真实多电压等级数据。建议用一个配置开关控制是否启用。

### 3.4 全局特征

可以加“从输入本身就能算出来”的全局量：

- 三个通道各自的已知比例；
- 已知 P/Q/V 的均值和标准差；
- 节点数、支路数、线路/变压器数量；
- 图的最大度、平均度。

不要加 `sigma`、`total_load_mw`、`loss_mw`、`mask_mode`、迭代次数。
这些不是推理时能拿到的量测，或者会泄漏场景难度。

全局特征的作用是让模型知道“这次量测有多完整、负荷大概在什么水平”。
对于 dropout 掩码，这个信息尤其有用。

### 3.5 归一化

v1 的做法：

- P/Q/V 只用训练集已知位置统计；
- 未知位置先标准化、再置 0；
- 截断到正负 6；
- 支路 R/X/B2 用训练拓扑统计；
- 六个标签分别用训练集统计。

这套做法基本正确，但有两个需要改的地方。

**第一，输入 V 和输出 Vm 用了不同的归一化。**
节点输入里的 V 用的是“已知位置”的均值和标准差；输出 Vm 用的是
“全部节点”的均值和标准差；已知 V 复制时又用输出统计量。
模型看到的是两个不同的电压尺度。v2 应该统一：

- 方案一：输入 V 和输出 Vm 都用训练集全部节点的统计量；
- 方案二：都用固定物理缩放，例如 `(V - 1.0) / 0.05`。

固定缩放的好处是跨算例更稳，不依赖训练集分布。当前数据 V 的范围
大约 0.955 到 1.064，固定缩放后落在正负 1.3 左右，很合适。

**第二，P/Q 的标准化对 Q 的极端值比较敏感。**
structural 下 Q 只在 PQ 节点已知；extra 会揭示 PV 节点的 Q，
可能出现 600 MVar 以上的值。建议：

- 用稳健统计（中位数和四分位距）或固定物理缩放；
- 记录标准化后超过截断阈值的比例；
- 如果截断比例很高，说明统计量或缩放方式不合适。

P/Q 也可以直接用“除以 baseMVA”的标幺值作为输入，再做一次温和的
线性缩放。这样跨算例更稳，不依赖具体负荷水平。

### 3.6 掩码和未知位置

顺序不能乱：

1. 复制原始数值；
2. 用训练集统计量标准化；
3. 把 `mask == 1` 的位置置 0；
4. 截断；
5. 和掩码拼接。

不能先置 0 再标准化，否则未知位置会变成一个固定的非零值。
也不能只置 0 不标准化，否则 P/Q 的几百 MW 会压过 V 的 1 p.u.。

未知位置不要填邻居平均、全网平均或潮流解：

- 邻居平均是模型自己编造的信息；
- 全网平均会让未知位置看起来像真实量测；
- 填潮流解就是泄漏标签。

保持 0，让掩码去解释它。

### 3.7 图结构

- `edge_index` 是 `[2, E]`，`[0]` 是首端，`[1]` 是末端；
- 原始边只有单向记录；
- 消息传递时补反向边，变成 `[2, 2E]`；
- 支路输出头只读原始方向的 E 条边；
- 反向边复制 R/X/B2 和类型，只加一个方向标志；
- 并联支路是多条边，不要合并；如果 R/X/B2 完全相同，加并联标志。

当前 case39 没有并联支路，但真实数据会有。图结构本身支持多重边，
问题只在于边特征是否能区分它们。

### 3.8 批处理

当前所有样本都是 39 节点、46 支路，可以直接堆成 `[B, N, 6]`、
`[B, E, 6]`。补零逻辑已经为以后多拓扑留了接口。

注意两个细节：

- 补零位置的 `node_valid`、`edge_valid` 必须为 0；
- 支路头不能用补零边或反向边算损失；
- 归一化器要和模型一起保存，推理时不能重新按测试集拟合。

## 4. 数据划分与场景覆盖

### 4.1 当前划分

- 2000 条样本，按 80/10/10 分成 1602/199/199；
- 按 `case_hash` 分组；
- 按 `(mask_mode, sigma 分位)` 分层；
- 保存到 `split.json`。

这个划分能保证同一个 `case_hash` 不跨集合，但有一个问题：

> `case_hash` 是对**掩码后的输入**做哈希，不是对物理场景做哈希。

同一个负荷场景如果配了两种掩码，`case_hash` 会不同，可能一个进训练、
一个进测试。当前生成脚本每个场景只配一种掩码，所以没有实际泄漏；
但以后做“同一场景多种掩码”的数据增强时，这个划分会漏。

**建议：增加 `scenario_hash`。** 用拓扑、未掩码的负荷向量、发电机出力、
电压设定值做哈希，按 `scenario_hash` 分组。掩码只作为场景内的变化，
不参与分组。

### 4.2 三种划分要分开

| 划分 | 训练 | 测试 | 回答什么问题 |
|---|---|---|---|
| 插值划分 | 同拓扑，随机场景 | 同拓扑，随机场景 | 同分布下拟合得好不好 |
| 外推划分 | 低负荷/中等负荷 | 高负荷 | 负荷超出训练范围时会不会崩 |
| 拓扑留出 | 一部分拓扑 | 完全不同拓扑 | 能不能迁移到新网架 |

当前只有第一种。第二种可以用 `sigma` 做：训练只用 `sigma <= 1.0`，
测试用 `sigma > 1.0`。第三种需要多拓扑数据。

不要用插值划分的指标宣称“泛化能力”。它只说明模型在同类场景上
拟合得不错。

### 4.3 当前数据的局限

当前数据：

- 一张拓扑；
- 只扰动负荷，`sigma` 在 0.8 到 1.1；
- 发电机出力固定；
- PV/平衡节点电压设定值固定；
- 没有线路停运、没有拓扑变化；
- 没有多电压等级、没有并联支路。

这意味着数据里的变化主要是“全网负荷整体缩放 + 小扰动”。
很多输出和负荷之间近似线性，线性基线因此很强。GNN 的图结构
优势不容易体现。

### 4.4 数据 v2 建议

按优先级：

1. **发电机有功出力变化**：在机组上下限内采样，保持 P 平衡；
2. **PV/平衡节点电压设定值变化**：让无功和电压分布更有变化；
3. **负荷结构变化**：不只整体缩放，改变各节点负荷比例和 P/Q 比例；
4. **拓扑变化**：线路停运、N-1、不同网架；
5. **多电压等级和并联支路**：让电压等级、并联标志真正有信息量；
6. **掩码模式平衡**：不要 70% 都是 structural；训练时做加权采样。

数据变化比模型结构更重要。当前数据下图结构带来的收益有限，
不是 GNN 不行，而是数据没有给图结构发挥的空间。

## 5. 输出参数化

### 5.1 v1 的做法

- 节点头输出 Vm；
- 支路头输入首端节点状态、末端节点状态、原始边状态，输出五个量；
- 五个量共用一个头，独立回归；
- 已知 V 在输出阶段直接复制。

### 5.2 直接回归的问题

**第一，五个支路量之间没有硬约束。**
首端有功、末端有功、首端无功、末端无功是同一组电压和相角的函数。
独立回归可以拟合得不错，但可能出现：

- 首端有功加末端有功为负，违反损耗非负；
- 支路两端功率和节点注入对不上，违反节点功率平衡；
- 相角差和支路功率不一致。

**第二，支路头没有直接看到预测的 Vm 和相角差。**
它看到的是节点隐状态和边隐状态。已知 V 在输出阶段被精确复制，
但这个精确值没有显式传给支路头。支路潮流对端点电压很敏感，
应该把 Vm 和相角差显式喂给支路头。

**第三，变压器变比缺失的误差集中。**
branch 13 的变比是 1.07，它的相角差和有功误差远高于平均。
模型没有变比输入，只能从标签中间接学。独立回归能部分补偿，
但没有显式的支路级校准参数。

**第四，首末端有功高度冗余。**
`Pf + Pt` 是支路有功损耗，通常远小于潮流本身。独立预测两个量
浪费容量，也不保证一致。

### 5.3 方案 A：直接回归加物理一致性损失

这是低风险方案，不改输出结构，只加约束。

**节点功率平衡损失。**
对每个已知 P/Q 的节点，把与它相连的支路潮流加起来，应该等于
该节点的已知净注入。只对已知位置算损失，未知位置跳过。
这个损失不需要变比，也不需要相角，直接约束 KCL。

**支路损耗符号。**
`Pf + Pt` 应该大于等于 0。可以加一个很轻的惩罚，防止出现负损耗。

**每支路偏置校准。**
在训练集上算每条支路每个输出的平均残差，推理时加回去。
这是一个很便宜的后处理，实测能让有功和相角差再降 7% 到 8%。
它不能替代模型改进，但可以作为 baseline 的一部分。

**线性跳连。**
在模型输出上加一条从原始节点/边特征到输出的线性通路。
岭回归基线说明线性部分很强，GNN 应该学残差，而不是从零学线性映射。

### 5.4 方案 B：节点角度加解析支路潮流

这是高潜力方案，物理最干净。

1. 节点头输出两个量：Vm 和节点相角 theta；
2. 支路相角差直接由 `theta_from - theta_to` 得到；
3. 支路有功无功用标准 pi 型等值电路公式，从 Vm、相角差、R/X/B2
   和变比算出来；
4. 只保留一个支路头输出相角差，或者连相角差也由节点角度得到。

如果变比已知，这个方案在数值上可以精确复现标签。实测用真实 Vm、
真实相角差和真实变比复算，误差在 1e-12 量级。问题是变比未知。

如果变比按 1 处理，变压器支路的误差很大：

| 输出 | 全部支路 MAE | 线路 MAE | 变压器 MAE |
|---|---:|---:|---:|
| Pf | 3.93 MW | 0.00 MW | 15.06 MW |
| Qf | 48.7 MVar | 0.00 MVar | 186.8 MVar |

线路完全精确，变压器完全不准。所以**不能直接对变压器用变比 1 的
解析式**。两个可行做法：

- 拿到真实变比，直接代入；
- 拿不到变比，就给每条支路一个可学习的等效变比，初始化为 1，
  只用标签监督。固定拓扑下只有 46 个参数，成本很低。

可学习等效变比不是 `aux_tap` 的输入，也不是它的初始化。
它是从标签中拟合出来的校准参数。换拓扑后不能直接迁移，
需要重新拟合或用边特征预测。

### 5.5 方案 C：混合或残差

- 直接回归五个支路量，同时用解析式算一组“物理预测”，让网络学残差；
- 或者 GNN 先预测 Vm、相角、缺失注入，再用一个可微的潮流层做几步修正。

后者更复杂，但上限更高。建议在方案 A/B 都跑过之后再考虑。

### 5.6 变比怎么处理

推荐顺序：

1. **v1 现状**：不输入变比，直接回归。简单，变压器误差偏大；
2. **每支路可学习等效变比**：固定拓扑下最直接，46 个参数，
   从标签学，不碰 `aux_tap`；
3. **从边特征预测变比**：多拓扑时用，输入 R/X/B2、类型、首末端
   电压等级比，输出一个等效变比；
4. **拿到真实变比**：直接输入或代入解析式，这是最好的情况。

不要在 v1 里把“变比按 1”写进物理复算，然后又用复算结果去监督模型。
那会把建模误差当成模型错误。

### 5.7 已知电压复制

保持 v1 的做法：

- `mask_v == 0` 的节点，输出直接复制输入电压；
- 训练时 Vm 损失只算 `mask_v == 1` 的节点；
- 评估时已知/未知分开报告。

v2 如果做解析支路潮流，要把复制后的 Vm 显式传给支路头，
让支路潮流用上精确的已知电压。

## 6. 模型架构

### 6.1 v1 的结构

```text
节点特征 [B,N,6] -> 节点编码器 -> 节点隐状态 [B,N,H]
边特征   [B,E,6] -> 边编码器   -> 边隐状态   [B,E,H]
                                      |
                                 L 层边感知消息传递
                                      |
                       +--------------+--------------+
                       |                             |
                  节点输出头                     支路输出头
                  Vm [B,N]              dtheta/Pf/Pt/Qf/Qt [B,E,5]
```

- 节点编码器：Linear -> LayerNorm -> GELU；
- 边编码器：多一列方向标志，原始边 0，反向边 1；
- 每层：消息 MLP、节点更新 MLP、边更新 MLP、残差、LayerNorm；
- 消息按末端节点做均值聚合；
- 支路头只读原始方向的边；
- 默认 hidden 128，6 层，dropout 0.1，约 1.16M 参数。

### 6.2 v1 架构的问题

**没有线性跳连。** 所有输出都要经过多层消息传递。对于近似线性的
负荷缩放数据，这会让模型学得很吃力。岭回归基线在相角差和有功上
更好，很可能就是这个原因。

**没有全局读出。** 每个节点只能通过邻居消息间接感知全网负荷水平。
39 节点、6 层虽然能覆盖，但全局信息会被稀释。加一个全局池化
（均值/最大值）再广播回节点，成本很低。

**均值聚合会稀释。** 高度数节点收到的消息被平均，可能弱化关键
邻居。可以试 sum 聚合、注意力聚合或门控聚合。当前图很小，
可以先做消融，不必直接上复杂注意力。

**支路头信息不足。** 它没有显式拿到预测的 Vm、相角差和原始边特征。
建议支路头输入改成：

```text
[首端节点隐状态, 末端节点隐状态, 边隐状态,
 首端 Vm, 末端 Vm, 相角差, 原始边特征]
```

**边类型三分类是互斥的。** 真实数据里变压器可能同时有变比和移相。
改成三个独立二值标志。

**层数可能过多或过少。** 6 层在 39 节点图上不算多，但也没有验证过。
2/4/6/8 层都要做消融，观察过平滑和验证损失。

### 6.3 v2 推荐结构

```text
节点特征（含节点类型、电压等级）
        |
   节点编码器
        |
   L 层边感知消息传递 <---- 全局读出（均值/最大值）
        |
        +--> 节点头 --> Vm, 节点相角 theta
        |
        +--> 支路头 --> 相角差, 支路潮流
        |
  原始特征的线性跳连 ----------------------+
                                            |
                                        输出相加
```

关键点：

1. 节点输入加节点类型 one-hot、电压等级；
2. 边输入加独立的线路/变压器/移相标志、首末端电压等级比；
3. 每层加全局上下文；
4. 节点头输出 Vm 和 theta（或只输出 Vm，支路头输出相角差）；
5. 支路头显式拿到两端 Vm、相角差、原始边特征；
6. 加一条从原始特征到输出的线性跳连；
7. 保留已知 V 复制。

### 6.4 线性跳连怎么做

节点侧：

```text
Vm = GNN_node_head(node_h) + Linear(node_x)
```

支路侧：

```text
branch_out = GNN_branch_head(...) + Linear([node_x_from, node_x_to, edge_attr])
```

线性项的输入只用原始特征，不经过消息传递。这样模型可以同时学
“近似线性的主效应”和“图结构带来的非线性修正”。

这不等于把岭回归硬编码进去。线性项的参数仍然由训练学习，
只是给模型一条更短的梯度通路。

### 6.5 支路头怎么改

v1：

```text
branch_head([h_from, h_to, edge_h]) -> 5 个输出
```

v2 建议：

```text
branch_head([h_from, h_to, edge_h,
             vm_from, vm_to, dtheta,
             raw_edge_features]) -> 5 个输出
```

如果采用方案 B，支路头可以只输出相角差，潮流由解析式算。
如果采用方案 A，支路头仍然输出五个量，但输入更完整。

### 6.6 超参数建议

| 参数 | v1 | v2 建议 |
|---|---:|---:|
| hidden | 128 | 128，消融 64/256 |
| 层数 | 6 | 4/6/8 消融 |
| dropout | 0.1 | 0.1，消融 0/0.2 |
| 聚合 | 均值 | 均值/sum/注意力消融 |
| 线性跳连 | 无 | 加 |
| 全局读出 | 无 | 加 |
| 节点类型 | 无 | 加 |
| 电压等级 | 无 | 加，配置开关 |
| 边类型 | 三分类 | 三个独立二值 |

## 7. 损失函数与训练

### 7.1 v1 的损失

六个输出各自标准化，做 Huber（Smooth L1），权重都是 1。
Vm 只在待预测节点算，五个支路量在所有有效支路上算。

问题：

- 标准化空间等权，不等于物理量等权；
- 支路有功输出通道的标准差约 347 MW，支路无功约 67 到 89 MVar，
  Vm 约 0.022 p.u.；
- 同样一个标准差的误差，对应的物理误差差别很大；
- 如果官方指标是物理 MAE，v1 会过度优化 Q 和 V，牺牲 P 和相角差。

v1 的结果正好符合这个判断：Q 很好，P 和相角差不如线性基线。

### 7.2 损失权重怎么定

推荐三步：

1. 先确认官方指标；
2. 如果官方指标是物理 MAE，就用物理量损失，或把标准化损失乘以
   每个通道的物理尺度；
3. 如果官方指标是按通道归一化的，就按官方归一化方式加权。

在官方指标未知时，至少同时训练/评估两组权重：

- 等标准化权重（v1）；
- 物理尺度权重，例如 `P: 1/100`、`Q: 1/50`、`V: 1/0.01`、
  `dtheta: 1/1`，具体数值按数据量级调。

不要只看一个总损失。分通道报告 MAE，才能看出权重有没有把某个量压坏。

### 7.3 节点功率平衡损失

这是最值得加的物理约束。对每个已知 P/Q 的节点：

```text
sum(与该节点相连的支路潮流) - 已知净注入 = 0
```

只对已知位置算，未知位置跳过。归一化可以用 baseMVA 或支路潮流尺度。

它不需要变比，不需要相角，直接约束 KCL。它能把支路潮流和节点注入
绑在一起，减少“每个支路单独拟合得很好，但全网对不上”的问题。

### 7.4 支路一致性

如果采用方案 A，可以加：

- `Pf + Pt >= 0` 的轻惩罚；
- 首端/末端有功之和与线路损耗的近似一致性；
- 如果采用方案 B，解析式本身已经保证一致性，不需要额外损失。

不要一上来加很多物理项。每加一项都要做消融，确认它带来的是
物理一致性还是只是把损失拉高。

### 7.5 角度辅助损失

如果采用节点角度参数化，可以用 `aux_va_deg` 做辅助监督，
但必须做参考相角处理：

- 选平衡节点，令它的相角为 0；
- 或者把预测和标签都减去各自均值，只监督相对角度。

辅助损失只在训练时用，推理时不输入 `aux_va_deg`。
如果比赛数据没有相角标签，这一项就不能用。

### 7.6 优化器和训练控制

v1 的配置可以作为起点：

| 项目 | 值 |
|---|---:|
| 优化器 | AdamW |
| 学习率 | 1e-3 |
| 权重衰减 | 1e-4 |
| 调度器 | ReduceLROnPlateau，factor 0.5 |
| 梯度裁剪 | 1.0 |
| 批大小 | 64 |
| 最大轮数 | 150 到 300 |
| 早停 | 验证指标 25 到 30 轮不降 |

v2 建议：

- 早停指标改成物理量综合分，不再用标准化 Huber；
- 跑 3 个随机种子，报告均值和标准差；
- 可以加 EMA（指数滑动平均）稳定后期；
- 混合精度可选，当前模型很小，收益有限；
- 数据加载用 `cache_shards=True`，避免随机访问反复解压。

### 7.7 掩码模式平衡

当前数据 structural 约 69%，dropout 约 21%，extra 约 10%。
如果直接随机采样，模型会偏向 structural。

建议：

- 训练时按掩码模式做加权采样，让三种模式每个 epoch 的样本数接近；
- 或者给 dropout 样本更高的损失权重；
- 评估时三种模式分开报告。

dropout 是当前最难的模式，也是最需要模型学先验的模式。
如果它一直最差，说明模型没有真正学会补缺失量测。

## 8. 评测、基线与消融

### 8.1 指标口径

每个输出都报告：

- MAE；
- RMSE；
- 最大绝对误差；
- 样本数；
- 归一化 MAE（除以训练集标准差或固定物理容差）。

拆分维度：

- Vm：全部节点、待预测节点、已知节点；
- 五个支路量：全部支路、线路、变压器、移相变压器；
- 三种掩码模式：structural、dropout、extra；
- 负荷水平：高负荷 20% 子集；
- 支路潮流大小：高流量支路和低流量支路分开看。

已知节点的 Vm 误差接近 0，不能让它把整体指标拉高。
支路误差要按类型分开，否则变压器的大误差会被线路平均掉。

### 8.2 必做基线

按实现成本从低到高：

1. **均值基线**：每个输出用训练集均值。  
   只用来确认模型不是“学了个均值”。

2. **岭回归/线性基线**：输入是掩码后的 P/Q/V、三个掩码、已知量汇总。  
   当前数据下这个基线很强，是 v1 必须打败的对手。

3. **牛顿法/状态估计基线**：  
   - structural：直接解标准潮流，理论上精确；
   - extra：最小二乘；
   - dropout：加伪量测或正则化，可能需要先验。  
   如果比赛允许数值求解，这是上限基线；如果不允许，也用它做误差分析。

4. **无图 MLP**：每个节点只看自己的 P/Q/V 和掩码，不看邻居。  
   用来验证图结构有没有收益。

5. **全局 MLP**：把所有节点特征拼成一个长向量，输出全部标签。  
   参数量大，容易过拟合，但能检验“全局线性映射”有多强。

6. **GNN v1**：当前模型。

7. **GNN v2**：加输入特征、线性跳连、物理损失后的模型。

如果 GNN 不比岭回归好，先不要加层。先检查损失权重、线性跳连、
输入特征和数据划分。

### 8.3 v1 与基线对比

| 输出 | v1 GNN | 岭回归 | 均值基线 |
|---|---:|---:|---:|
| Vm（未知） | 0.00088 p.u. | 0.00686 p.u. | 0.00439 p.u. |
| 相角差 | 0.0875 度 | 0.049 度 | 0.572 度 |
| Pf | 9.38 MW | 4.56 MW | 62.8 MW |
| Pt | 9.38 MW | 4.57 MW | 62.8 MW |
| Qf | 2.25 MVar | 4.82 MVar | 10.9 MVar |
| Qt | 2.49 MVar | 5.90 MVar | 11.7 MVar |

结论：

- v1 明显好于均值基线，说明模型学到了东西；
- v1 在 Vm 和无功上明显好于线性基线；
- v1 在相角差和有功上不如线性基线，这是下一步必须解决的问题；
- 线性基线是“同分布插值”的强对手，不能用“GNN 比均值好”来证明架构成功。

这份岭回归结果是本地快速实验，还没有入库。建议下一步把它做成
`src/examples/baseline_linear.py`，用同一份 `split.json` 复现。

### 8.4 误差分析

当前已知的重点：

- 误差集中在变比明显偏离 1 的变压器，例如 branch 13（变比 1.07）；
- branch 13 的相角差 MAE 约 0.89 度，是全站平均的 10 倍；
- 每支路偏置校准能让有功/相角差降 7% 到 8%，说明支路级修正有效；
- dropout 模式最差，符合信息越少越难的预期；
- extra 模式的支路误差反而比 structural 高，需要进一步查，
  可能是 PV 节点 Q 的极端值导致归一化偏移。

建议每次训练后自动输出：

- 误差最大的 10 条支路；
- 误差最大的 10 个样本；
- 按支路类型、掩码模式、负荷水平的误差表；
- 已知/未知 V 的分开指标；
- 节点功率平衡残差。

### 8.5 消融优先级

| 优先级 | 消融 | 目的 |
|---|---|---|
| 高 | 损失权重：标准化 vs 物理尺度 | 看 P/相角差是否能追上线性基线 |
| 高 | 线性跳连 | 看 GNN 是否只需要学残差 |
| 高 | 节点类型 one-hot | dropout 下是否涨点 |
| 高 | 每支路偏置/等效变比 | 变压器误差是否下降 |
| 中 | 全局读出 | 全网负荷信息是否被稀释 |
| 中 | 电压等级/首末端电压比 | 当前常数，预期无收益；为真实数据铺路 |
| 中 | 聚合方式：均值/sum/注意力 | 是否过平滑或稀释 |
| 中 | 层数 2/4/6/8 | 感受野和过平滑 |
| 中 | hidden 64/128/256 | 容量瓶颈 |
| 低 | 支路五头拆开 | 共享头是否拖累某个量 |
| 低 | 反向边去掉 | 双向消息是否必要 |
| 低 | 关闭已知 V 复制 | 送分题复制是否影响其他节点 |

所有消融必须用同一份 `split.json`、同一套归一化器、同一组随机种子。
否则结果不可比。

### 8.6 统计显著性

当前测试集只有 199 条样本，指标有随机波动。建议：

- 每个配置跑 3 个种子；
- 报告均值和标准差；
- 对测试集做 bootstrap，给 MAE 的置信区间；
- 不要因为 1% 到 2% 的差异就宣布某个模块有效。

### 9.2 第一阶段：基线和指标（最高优先级）

目标：确认 v1 到底处在什么水平，不再盲目调模型。

6. 输出误差最大的支路和样本。

完成标准：能回答“GNN 在哪些输出上赢线性基线、哪些输出上输”。

### 9.3 第二阶段：输入和架构（低成本改进）

1. 节点类型 one-hot；
2. 电压等级、首末端电压等级比（配置开关）；
3. 独立二值支路类型标志；
4. 线性跳连；
5. 全局读出；
6. 损失权重按官方指标调整；
7. 掩码模式平衡采样。

完成标准：v1 在所有输出上不输给岭回归，最好在相角差和有功上明显更好。

### 9.4 第三阶段：输出参数化（物理一致性）

1. 节点功率平衡损失；
2. 支路头显式输入预测 Vm、相角差；
3. 每支路偏置校准；
4. 每支路可学习等效变比；
5. 节点角度参数化 + 解析支路潮流；
6. 对比方案 A/B/C。

完成标准：变压器支路误差明显下降，节点功率平衡残差变小。

### 9.5 第四阶段：数据 v2

1. 发电机出力变化；
2. PV/平衡节点电压设定值变化；
3. 负荷结构变化；
4. 拓扑变化；
5. 多电压等级和并联支路；
6. 重新做场景哈希和划分。

完成标准：在拓扑留出或负荷外推划分上，模型仍然稳定。

### 9.6 当前不要做的事

- 不要把 `aux_net_*`、`aux_va_deg` 加进输入；
- 不要用 `aux_tap`、`aux_shift_deg` 做输入或初始化；
- 不要用测试集重新拟合归一化器；

- 不要用标准化 Huber 的下降来证明模型变好；
