# 1.1 ~ 1.7　案例数据：系统介绍与三张核心表

> 系统背景、数据来源、规模总览、bus/gen/branch/gencost 逐列讲解

## 1.1 这是什么系统

**IEEE 39 节点系统**，全名 **New England 系统**（新英格兰是美国东北部地区）。
它是电力系统研究里最经典的算例之一，1970 年代由美国电力研究院（EEI）的
RP90-1 项目建立，用来研究新英格兰地区 345 kV 输电网的稳定问题。

它常被引用的三个出处：

- G. W. Bills et al., *On-Line Stability Analysis Study*, EEI RP90-1, 1970
- M. A. Pai, *Energy Function Analysis for Power System Stability*, 1989
- Athay, Podmore, Virmani, *A Practical Method for the Direct Analysis of
  Transient Stability*, 1979

它的结构很好记：**10 台发电机围成一圈，通过一个 39 节点的输电网给负荷供电**，
是一个典型的高压输电网骨架。因为规模适中（比 9 节点的 case9 复杂，又比几百节点的
真实电网小得多），它成了学习潮流计算、暂态稳定、最优潮流的"标准练兵场"。

## 1.2 数据从哪里来

本教程的数据来源是 PYPOWER 自带的 `pypower.case39`：

```python
from pypower.api import case39

ppc = case39()
print(ppc.keys())
# dict_keys(['version', 'baseMVA', 'bus', 'gen', 'branch', 'gencost'])
```

`ppc` 是 **PYPOWER case 格式**（power flow case），就是几个大矩阵：

| 键 | 形状 | 含义 |
|---|---|---|
| `baseMVA` | 标量 | 基准容量，`100.0` MVA |
| `bus` | 39 × 13 | 母线（节点）表 |
| `gen` | 10 × 21 | 发电机表 |
| `branch` | 46 × 13 | 支路表（线路 + 变压器） |
| `gencost` | 10 × 7 | 发电成本系数（潮流计算用不到，最优潮流才用） |
| `version` | 标量 | 数据格式版本，`2` |

**注意 `baseMVA = 100 MVA`**。这是全系统标幺化的基准，后面所有"标幺值(pu)"
都要乘它才是真实的 MW / Mvar / MVA。这一点非常重要，初学者最容易在这里搞混。

## 1.3 数据总览

| 元素 | 数量 |
|---|---:|
| 母线 bus | 39 |
| 发电机 gen | 10 |
| 支路 branch | 46 |
| —— 其中普通线路（`tap = 0`） | 34 |
| —— 其中变压器等值支路（`tap ≠ 0`） | 12 |
| 带负荷的母线 | 21 |
| 基准容量 | 100 MVA |
| 总有功负荷 | 6254.23 MW |
| 总无功负荷 | 1387.10 Mvar |
| 电压等级 | 全部 345 kV |

有几个数字值得单独强调：

- **46 = 34 + 12**（按 PYPOWER 的 `tap_pu` 标记）或 **46 = 35 + 11**
  （按“变比是否 ≠ 1”分）。PYPOWER 把线路和变压器**放在同一张 branch 表里**，
  靠 `tap_pu` 列区分：`tap = 0` 是纯线路，`tap ≠ 0` 是变压器等值支路。
  这 12 条里有一条（母线 23→36）变比恰好是 `1.0`，电气上等同于线路，
  所以按设备类型数只有 11 台真正改变电压的变压器。
  赛事对齐数据集采用第一种标记（34 条线路 + 12 条变压器支路），
  并把原始 `tap` 保存在 `aux_tap` 里；两种数法都能从数据中恢复。
- **全系统只有一个电压等级 345 kV**。变压器在这里不是"升压/降压"，而是
  **等值阻抗支路**（用变比模拟等值阻抗折算），所以它们两端都是 345 kV。
- **39 个母线里只有 21 个接了负荷**，其余 18 个的 `Pd = Qd = 0`；其中 8 个接
  发电机（30、32–38），另外 10 个（2、5、6、10、11、13、14、17、19、22）
  是纯联络节点。

## 1.4 `bus` 表：母线数据（逐列讲解）

`bus` 是 39 × 13 的浮点矩阵。列的含义（PYPOWER 的列索引定义在
`pypower.idx_bus`）：

| 列号 | 常量名 | 含义 |
|---:|---|---|
| 0 | `BUS_I` | 母线编号，1 ~ 39 |
| 1 | `BUS_TYPE` | 节点类型：1 = PQ，2 = PV，3 = 平衡节点 |
| 2 | `PD` | 有功负荷，MW |
| 3 | `QD` | 无功负荷，Mvar |
| 4 | `GS` | 并联电导，MW（本算例全为 0） |
| 5 | `BS` | 并联电纳，Mvar（本算例全为 0） |
| 6 | `AREA` | 所属区域号 |
| 7 | `VM` | 电压幅值，pu |
| 8 | `VA` | 电压相角，度 |
| 9 | `BASE_KV` | 基准电压，kV（本算例全为 345） |
| 10 | `ZONE` | 分区号 |
| 11 | `VMAX` | 电压幅值上限，pu（本算例全为 1.06） |
| 12 | `VMIN` | 电压幅值下限，pu（本算例全为 0.94） |

两个关键理解：

1. **第 7、8 列的 `VM`、`VA` 是"初值"，不是"结果"**。它们告诉求解器从哪个
   电压猜测值开始迭代。后面 2.9 节会讲，这个算例的初值**恰好已经非常接近答案**，
   这是它一个很特别的地方。
2. **`PD`、`QD` 的正负号很重要**。正数表示"消耗无功/有功"（普通负荷），
   负数表示该节点实际上在**发出**无功。本算例里母线 9 和 24 的 `QD` 是负数
   （-66.6 和 -92.2 Mvar），说明这两个负荷点带了无功补偿。

## 1.5 `gen` 表：发电机数据

`gen` 是 10 × 21 的矩阵，前 10 列最常用（定义在 `pypower.idx_gen`）：

| 列号 | 常量名 | 含义 |
|---:|---|---|
| 0 | `GEN_BUS` | 发电机接在哪条母线 |
| 1 | `PG` | 有功出力，MW |
| 2 | `QG` | 无功出力，Mvar |
| 3 | `QMAX` | 无功上限，Mvar |
| 4 | `QMIN` | 无功下限，Mvar |
| 5 | `VG` | 电压幅值设定值，pu |
| 6 | `MBASE` | 机组基准容量，MVA（全为 100） |
| 7 | `GEN_STATUS` | 投运状态，> 0 表示在运行 |
| 8 | `PMAX` | 有功上限，MW |
| 9 | `PMIN` | 有功下限，MW（全为 0） |

发电机接在母线 **30 ~ 39** 上，正好是连续编号的 10 条母线。其中：

- 母线 31 的发电机是**平衡机**（slack）；
- 其余 9 台（母线 30、32 ~ 39）是 **PV 节点**。

对 PV 节点，`PG` 和 `VG` 是**已知量**（调度给定的），`QG` 要**解出来**。
对平衡机，`PG` 和 `QG` **都是解出来的**——它负责兜底整个系统的功率缺额。

## 1.6 `branch` 表：支路数据

`branch` 是 46 × 13 的矩阵（定义在 `pypower.idx_brch`）：

| 列号 | 常量名 | 含义 |
|---:|---|---|
| 0 | `F_BUS` | 首端母线 |
| 1 | `T_BUS` | 末端母线 |
| 2 | `BR_R` | 串联电阻，pu |
| 3 | `BR_X` | 串联电抗，pu |
| 4 | `BR_B` | 总充电电纳，pu |
| 5 | `RATE_A` | 长期容量，MVA |
| 6 | `RATE_B` | 短期容量，MVA |
| 7 | `RATE_C` | 紧急容量，MVA |
| 8 | `TAP` | 变比，pu（0 表示"无变压器"，按 1 处理） |
| 9 | `SHIFT` | 移相角，度（本算例全为 0） |
| 10 | `BR_STATUS` | 投运状态，> 0 表示运行 |
| 11 | `ANGMIN` | 首末端相角差下限，度 |
| 12 | `ANGMAX` | 首末端相角差上限，度 |

**本算例的支路全是 r、x、b 都很小的数值（10⁻³ ~ 10⁻² 量级），因为它们是标幺值。**
真实 345 kV 线路的电阻大约是几欧姆，除以阻抗基准值 Z_base = V²/S = 345²/100
= 1190 Ω 之后，就变成了 0.0035 这种量级。

## 1.7 `gencost` 表：发电成本

每个发电机用二次多项式表示成本：

$$C(P) = c_2 P^2 + c_1 P + c_0$$

本算例全部 10 台机组都是：

```text
c2 = 0.01,  c1 = 0.3,  c0 = 0.2
```

**潮流计算不会用到 `gencost`**，它是给最优潮流（OPF）用的。放在这里只是为了
数据完整。
